# 品赞HTTP代理签到脚本 - 详细说明

## 📋 项目概述

这是一个自动化签到脚本，用于品赞(ipzan.com)平台的每日签到功能。

## 🔍 核心功能

### 1. 账号信息处理流程

```
账号密码 → Base64编码 → 随机混淆 → 加密账号信息
```

详细步骤：
1. **拼接信息**：`手机号 + "QWERIPZAN1290QWER" + 密码`
2. **UTF-16转UTF-8**：自定义编码处理
3. **Base64编码**：生成编码字符串
4. **随机混淆**：用16进制随机字符串打乱编码
5. **最终输出**：按照特定规则重组字符串

### 2. 登录流程

- **接口**：`https://service.ipzan.com/users-login`
- **方法**：POST
- **认证方式**：混淆后的账号信息
- **返回**：Token用于后续操作

### 3. 余额查询流程

- **接口**：`https://service.ipzan.com/home/userWallet-find`
- **方法**：GET
- **认证方式**：Bearer Token
- **功能**：查询当前账户余额和钱包信息
- **返回字段**：
  - `balance`: 总余额
  - `bonus_amount`: 奖励金额
  - `real_amount`: 真实金额
  - `levelReward`: 等级奖励状态

### 4. 签到流程

- **接口**：`https://service.ipzan.com/home/userWallet-receive`
- **方法**：GET
- **认证方式**：Bearer Token
- **功能**：领取每日奖励

## 📁 配置文件

### 支持两种方式配置账号：

#### 方式1：环境变量
```bash
# 设置环境变量
export pzhttp="18888888888#a18888888888"

# Windows PowerShell
$env:pzhttp="18888888888#a18888888888"
```

#### 方式2：配置文件（推荐）
创建 `config.txt` 文件：
```
18888888888#a18888888888
账号2#密码2
账号3#密码3
```

**格式**：每行一个账号，格式为 `手机号#密码`

## 🔐 安全机制

### 1. Base64 混淆算法

自定义Base64编码表，用于：
- UTF-16 → UTF-8 字符转换
- 实现类似标准Base64的编码
- 增加逆向难度

### 2. 账号信息混淆

```
生成400字符的随机16进制字符串
分段插入编码后的账号信息：
- 位置0-100：随机字符串
- 位置100-108：编码后前8个字符
- 位置108-208：随机字符串
- 位置208-220：编码后第8-20个字符
- 位置220-320：随机字符串
- 位置320-end：编码后剩余字符
- 最后一段：随机字符串
```

这种方式使得账号信息被随机字符串包围，难以直接提取。

## 📊 API 流程

```
1. 读取账号配置
   ↓
2. 生成混淆账号信息
   ↓
3. POST /users-login (登录)
   ↓
4. 获取Token
   ↓
5. GET /home/userWallet (查询余额)
   ↓
6. 显示余额信息
   ↓
7. GET /home/userWallet-receive (签到)
   ↓
8. 显示结果
```

## 🔧 技术细节

### 依赖库
- `requests`：HTTP请求
- `json`：JSON数据处理
- `random`：生成随机字符串
- `string`：字符串工具

### HTTP Headers
脚本模拟了浏览器请求，包含：
- User-Agent：Chrome/Edge浏览器标识
- Authorization：Bearer Token认证
- Referer & Origin：防跨站请求
- Cookie：语言设置

### 超时设置
- 登录请求：10秒超时
- 签到请求：10秒超时

## ⚠️ 注意事项

1. **账号安全**：不要将 `config.txt` 上传到公共仓库
2. **网络要求**：需要稳定的网络连接到 ipzan.com
3. **错误处理**：登录失败会跳过签到
4. **编码格式**：文件使用UTF-8编码
